Pasang di Layar Utama Android

Langkah di Google Chrome Android:

  1. Ketuk ikon titik tiga (⋮) di pojok kanan atas browser Chrome.
  2. Pilih menu "Tambahkan ke Layar utama" (Add to Home screen) atau "Instal aplikasi".
  3. Beri nama Cek Absen lalu ketuk Tambahkan.
  4. Taruh ikonnya tepat di samping ikon browser absen kantor Anda agar selalu terlihat setiap buka HP!

*Data disimpan menggunakan Persistent LocalStorage browser HP Anda. Selama cache situs tidak dihapus manual, log akan tersimpan selamanya.

Cadangkan & Pulihkan Data

Ekspor log absensi ke file JSON atau CSV (Excel) sebagai bukti cadangan permanen jika sewaktu-waktu Anda ganti HP.
